# EmoSense AI

## Project Overview

EmoSense AI is a prototype of an AI-assisted emotional support platform.

The goal of the project is to understand a user's emotional state through conversation and provide supportive responses. If the conversation indicates that professional help may be beneficial, the system can recommend connecting with a qualified mental health professional.

---

## Objective

- Help users express their emotions.
- Provide supportive AI conversations.
- Encourage seeking professional help when appropriate.

---

## Features

- AI-assisted conversation
- Emotion-aware responses
- Therapist recommendation workflow
- User-friendly interface
